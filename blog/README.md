# Blog

The Blog tab is a first-class SPA route (`/blog`), same as Publications, Projects, and CV.

Individual posts stay as static HTML in this folder (one subdirectory per post, with `index.html`). The listing in the SPA currently mirrors the posts here. When you add a post, add the listing card in the SPA blog page as well as the static file.

Copy `_template.html` for a new post. Posts keep `chrome.js` so leaving an article still lands in the SPA with the right tab highlighted.
